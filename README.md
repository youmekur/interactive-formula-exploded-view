# IFEV — Interactive Formula Exploded View

A dependency-free interactive formula annotation prototype for STEM education.

**Status:** v0.1.0 prototype; UX design frozen at V6.4. This is not yet a general-purpose library.

## Design

- Centered, intact mathematical formula
- Surrounding semantic annotations connected by SVG leader lines
- Click-to-focus interaction: the original formula symbol remains in place
- Light pulse travels along the connector to its annotation
- Adjustable parameters and live calculation in the reference demo

## Current status

The public repository has been initialized with its open-source license and project description. **The interactive HTML example and framework specification are not uploaded yet.** They are available in the separately prepared source archive.
